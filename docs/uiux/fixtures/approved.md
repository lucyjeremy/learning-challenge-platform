# 시안 A · 오늘의 미션 (Day 상세) — 승인 후보

- 대상 화면: SCR-DAY-01 Day 상세 + 인증, 진입은 첫 화면 SCR-EXP-01의 '오늘의 미션' 카드
- 첫 화면(스크롤 전): 상단에 "Day 9 · 리스트와 반복문", 그 아래 "오늘 23:59까지 인증해요", 화면 아래쪽에 고정된 파란 '인증하기' 버튼 하나. 사이드바의 '미션하러 가기'는 테두리 보조 버튼
- 상태
  - 인증 완료: "오늘 인증을 마쳤어요"와 받은 점수, 폼 대신 결과 카드
  - 오늘 미션 없음: "오늘은 쉬는 날이에요. 다음 Day는 내일 열려요"
  - 오류: "연결이 불안정해서 보내지 못했어요. 쓴 내용은 그대로 있으니 다시 시도해 주세요" + 버튼 다시 활성
  - 마감 지남: "아쉽지만 인증 마감(23:59)이 지났어요", 폼 숨김
- 반응형·접근성(설계 의도): 360px에서 1열, 본문 줄바꿈, 가로 넘침 없음. 모든 버튼에 포커스 링, Tab 순서는 제목 → 본문 입력 → 공개 범위 → 인증하기. 버튼 높이 44px
- 범위: 텍스트·링크·체크 인증까지. 사진 인증과 강사 확인은 "후속 단계"로 회색 안내만 표시
- 실행 기록: 없음 (설계 설명만)
