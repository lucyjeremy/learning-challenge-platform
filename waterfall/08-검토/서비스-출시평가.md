# 챌린지업 서비스 출시 평가 (2026-11-25)

## 한 줄 평가

지금 상태는 **기능 데모(체험판) 수준**이에요. 학생의 핵심 흐름(가입 → 신청 → 인증 → 피드 → 점수)은 서버 로직과 테스트로 동작하지만, 실제 돈을 받고 운영하려면 데이터 영속화, 실제 인증, 강사 도구, 결제가 필요해요.

| 관점 | 점수(5점) | 근거 |
|---|---|---|
| UI·UX (학생) | 3.5 | 다크 톤 일관, 해요체 문구, 마감·조기 인증 안내 명확. 사진 인증·댓글 화면 없음 |
| 핵심 기능 완성도 | 3 | 신청·인증·스트릭·포인트·좋아요 규칙이 서버에서 검증되고 46개 테스트 통과 |
| 운영 가능성 | 1 | 서버를 재시작하면 데이터가 사라짐(메모리 저장소). 강사·관리자 화면 없음 |
| 유료 서비스 준비도 | 1 | 결제·환불·약관·개인정보처리방침 없음 |

## 출시 전 꼭 필요한 것 (우선순위순)

1. **데이터 영속화와 실제 인증**: Supabase(Auth·Postgres) 연결. 마이그레이션 초안 `supabase/migrations/0001_init.sql` 준비됨. 지금 세션 쿠키는 데모용이라 운영에 쓰면 안 돼요.
2. **강사 스튜디오**: 챌린지 5단계 등록, Day별 영상·미션 편집, 인증 승인/반려, 완주 판정. 강사가 없으면 공급이 없어요.
3. **결제·환불**: 토스페이먼츠, 시작 전 취소 환불 규칙, 정산(플랫폼 20%/50% 모델).
4. **법적 고지**: 이용약관·개인정보처리방침 본문, 만 14세 미만 가입 제한.
5. **알림**: 마감 3시간 전 리마인드(이메일·웹 푸시). 매일 인증형 서비스의 완주율을 가장 크게 좌우해요.
