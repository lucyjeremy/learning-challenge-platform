## 3. 문구 수정 목록

- 오늘 인증 완료 → 오늘 인증을 마쳤어요
- 인증 완료 → 인증했어요
- 7 / 7 완료 → 7일 중 7일 인증
- 수정 완료 (글 수정 버튼) → 저장하기
- 글을 찾을 수 없어요. → 글을 찾을 수 없어요 (외 35곳 같은 규칙)

## 4. 영역별 상세

### A. 제품 원칙
| 원칙 | 판정 | 근거 |
|---|---|---|
| Casual Concept | 통과 | 'Day', '인증', '완주' 같은 쉬운 말. 완주 조건을 "21일 중 17일 인증하면 완주"로 풀어 씀 |
| Simple Policy | 통과 | 규칙은 매일 23:59 마감, 완주 기준 하나. 동시 참여 5개 제한은 걸릴 때만 안내 |
| Value First | 통과 | 비회원 홈 첫 문장이 얻는 것("같은 기수와 매일 인증하며 완주해요")부터 보여 줌 |
| Clear Action | 통과(수정 후) | 화면마다 파란 주요 버튼 하나 |
| Context Based | 통과 | 로그인 후 원래 보던 화면으로 복귀, 신청 후 바로 '챌린지 홈으로' |
| Easy to Answer | 개선 필요(남음) | 가입 시 이메일·비밀번호·비밀번호 확인·이름 4칸. 비밀번호 확인 칸은 '보기' 버튼으로 대체 가능 (제안) |
| Explain Why | 통과 | 이름 칸에 "피드와 순위표에 보이는 이름이에요" |
| One Thing | 통과(수정 후) | 사이드바 버튼 보조화 |
| No More Loading | 통과 | 서울 지역 배포 후 신청 0.4초, 좋아요 p95 0.36초. 처리 중 버튼 문구로 진행 표시 |
| Minimum Features | 통과 | 첫 화면 메뉴는 검색·카테고리·로그인뿐 |

### B. UX 라이팅
| 항목 | 판정 | 근거 |
|---|---|---|
| 해요체 | 통과 | 화면 문구에 '합니다·하시겠어요' 없음 (코드 전수 검색) |
| 능동·긍정형 | 통과 | 불가 안내는 이유와 함께 ("챌린지가 시작돼서 신청을 취소할 수 없어요. 인증하지 않은 Day는 미완주로 기록돼요") |
| '완료' 같은 딱딱한 말 | 통과(수정 후) | 문구 목록 참고 |
| CTA '~하기' | 통과(수정 후) | 신청하기·인증하기·게시하기·저장하기·글쓰기 |
| 두 버튼일 때 '취소' 대신 '닫기' | 통과 / 남음 | 글쓰기 창은 '취소'·'닫기(×)'. 삭제·닫기 확인은 브라우저 기본 확인창이라 버튼이 '확인/취소'로 고정됨 → 자체 확인창으로 바꾸기 (제안) |
| 오류 문구 | 통과 | 무엇이 문제인지와 다음 행동을 함께 ("정원이 다 찼어요. 비슷한 챌린지를 둘러볼까요?") |
| 일관성 | 통과(수정 후) | 마침표 통일 |
| 과장·자극 문구 | 통과 | 없음 |

### C. 접근성·반응형
| 항목 | 판정 | 근거 |
|---|---|---|
| 글자 200% | 통과 | Day 상세·내 강의실에서 가로 넘침 없음 |
| 말줄임 | 통과(수정 후) | 강의 목록 줄바꿈 |
| 모바일 폭 | 통과 | 375px 주요 9개 화면 가로 스크롤 없음 |
| 대체 텍스트·아이콘 레이블 | 통과 | 레이블 없는 버튼·링크 0개 (예: 글 메뉴 '⋯'에 aria-label) |
| 키보드·포커스 | 통과 | 이전 점검: 키보드만으로 가입 성공, 포커스 표시 항상 보임 |
| 색 대비 | 통과 | 이전 점검 axe 위반 0건 (배지 4.78:1) |
| 터치 영역 | 통과(수정 후) | 44px |
| 스크린 리더 | 확인 못 함 | 실기기 VoiceOver·TalkBack 미실행 |

### D. 다크패턴 방지
| 항목 | 판정 | 근거 |
|---|---|---|
| 첫 진입 팝업 | 통과 | 모든 화면 진입 시 열린 창 0개 |
| 이탈 방지 팝업 | 통과 | beforeunload 없음. 글쓰기 창은 쓴 내용이 있을 때만 "작성 중인 내용이 사라져요. 닫을까요?" (사용자 입력 보호) |
| 거절 방법 | 통과 | 글쓰기 창에 '취소'와 '×', Esc로 닫힘 |
| 미리 체크된 동의 | 통과 | 약관·개인정보 동의 모두 비어 있음 |
| CTA가 다음 일을 알림 | 통과 | "로그인하고 신청하기", "강의 보고 인증하기" |
| 거절 버튼 숨김·죄책감 | 통과 | 없음 |
| 전면 광고 | 해당 없음 | 광고 없음 |

### E. 그래픽·시각
| 항목 | 판정 | 근거 |
|---|---|---|
| 의미 있는 그래픽 | 통과 | 썸네일은 기간 숫자(예: 14일)를 크게 보여 주는 색면, 장식 일러스트 없음 |
| 화면당 강조 하나 | 통과(수정 후) | 주요 버튼 하나 |
| 상태 표시가 실제와 일치 | 통과 | 시작 전은 'D-2', 놓친 Day는 '–', 확인 중은 '…' |
| 애원·부정 감정 | 통과 | 없음 |
| 라이트/다크 | 개선 필요(남음) | 디자인 시스템이 어두운 테마 고정. 라이트 모드 사용자도 같은 어두운 화면이라 읽기는 가능 → 라이트 테마 추가 (제안) |

## 5. 확인하지 못한 것

- 실기기 스크린 리더(VoiceOver, TalkBack)로 핵심 흐름 끝까지 사용
- 강사·관리자 화면 (기능 미구현)
- 실제 iOS·Android 기기의 큰 글씨 모드 (브라우저 200% 확대로 대체)
