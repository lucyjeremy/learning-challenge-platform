## 1. 테스트 케이스 관리 규칙

### 1.1 작성 기준

| 항목 | 규칙 |
|------|------|
| **하나의 TC = 하나의 검증 목적** | 수용 기준 1개 또는 경계값 1묶음(허용·거절 쌍)을 검증 |
| **독립 실행 가능** | TC마다 자기 시드 데이터를 만들고 끝나면 지운다 |
| **재현 가능** | 시간 경계는 서버 시각 고정으로 재현 (실 시각에 의존하지 않음) |
| **사전조건 명시** | 역할, 챌린지 상태, 날짜, 시드 데이터 |
| **기대결과 명확** | 화면 문구(BP-ERROR-004), HTTP 상태·오류 코드(SRS 5.2.3), DB 변화 |
| **요구사항 추적** | FR·NFR·수용 기준 ID와 BP 규칙 ID를 반드시 기재 |

### 1.2 네이밍 규칙

형식은 `TC-{유형}-{영역}-NNN`이다 (RTM 부록 ID 체계). 보안 유형은 프로젝트에서 `SEC`를 쓴다.

| 접두사 | 유형 | 형식 | 예시 |
|--------|------|------|------|
| TC-FN | 기능 테스트 | TC-FN-[영역]-[번호] | TC-FN-SUB-001 |
| TC-SEC | 보안 테스트 | TC-SEC-[유형]-[번호] | TC-SEC-RLS-001 |
| TC-PF | 성능 테스트 | TC-PF-[대상]-[번호] | TC-PF-PAGE-001 |
| TC-CP | 호환성 테스트 | TC-CP-[환경]-[번호] | TC-CP-BRW-001 |
| TC-AC | 접근성 테스트 | TC-AC-[기준]-[번호] | TC-AC-KBD-001 |
| TC-OP | 운영 점검 | TC-OP-[대상]-[번호] | TC-OP-BAK-001 |
| TC-RG | 회귀 테스트 | TC-RG-[영역]-[번호] | TC-RG-SUB-001 |

영역 코드: AUTH(가입·로그인·프로필), INS(강사 신청), CHAL(등록·검수·수정·취소), JOB(상태 자동 전환), DISC(탐색·소개), ENR(신청), CUR(커리큘럼·오늘의 미션), SUB(인증), REV(강사 확인), FEED(피드), PT(포인트·레벨), STRK(스트릭), LB(리더보드), DONE(완주 판정), DASH(대시보드), MY(마이페이지), RPT(신고), TIME(시간 기준).

도구 표기: **V** = Vitest(단위), **P** = pgTAP/SQL(통합), **E** = Playwright(E2E), **M** = 수동, **L** = Lighthouse/Speed Insights.

### 1.3 상태 관리

| 상태 | 설명 | 표기 |
|------|------|------|
| Not Executed | 미실행 (현재 모든 TC) | 미실행 |
| Pass | 기대결과와 일치 | PASS |
| Fail | 기대결과와 불일치 (결함 등록) | FAIL |
| Blocked | 사전조건 미충족으로 실행 불가 | BLOCKED |
| Skipped | 의도적 건너뜀 (사유 기재) | SKIPPED |
| N/A | 해당 없음 | N/A |

### 1.4 신규 테스트 케이스 양식

| TC-ID | FR/NFR·수용 기준 | 사전조건·입력 | 절차 | 기대 결과 |
| --- | --- | --- | --- | --- |
| TC-{유형}-{영역}-NNN | FR·NFR ID / 수용 기준 ID / BP 규칙 ID | 역할, 데이터, 서버 고정 시각, 입력값 | 실행 순서 | 관찰 가능한 결과와 부수 효과(DB·포인트 로그) |

| TC-ID·실행일 | 커밋·빌드와 환경 | 실제 결과·판정 | 실행자·증빙 | 결함·후속 조치 |
| --- | --- | --- | --- | --- |
| (실행 기록 없음) | 후보 빌드 없음 | 전 TC 미실행 | - | - |

케이스 정의는 [RTM](../01-요구사항분석/요구사항추적매트릭스-RTM.md)에 연결했다. 최종 판정은 [결과 보고서](테스트결과보고서.md)에 반영한다.

아래 2~3장 표는 공통 열을 쓴다: **TC-ID / 요구사항·수용 기준 / 정책 규칙 / 사전조건·입력 / 절차 / 기대 결과 / 도구 / 상태**.
