전체는 [테스트 케이스 문서](테스트케이스.md) 부록 C의 고유 TC 153건이다 (회귀 세트 TC-RG 13건은 기존 TC를 묶은 것이라 따로 세지 않는다).

- **실행률** = (통과 + 실패) / (전체 − 해당 없음) × 100 = 0 / 153 = **0%**
- **통과율** = 통과 / (통과 + 실패) × 100 = 0 / 0 → **산정 불가**

미실행 사유: 테스트 대상 빌드가 없다. 전 TC 공통 사유이며, 시간 경계 TC는 추가로 서버 시각 고정 방법이 결정되지 않았다 (테스트 계획서 R-02).
