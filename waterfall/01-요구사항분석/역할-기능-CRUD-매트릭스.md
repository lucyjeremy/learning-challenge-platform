# 역할·기능 CRUD 매트릭스

| 항목 | 내용 |
|------|------|
| 문서 ID | CRUD-CHALLENGEUP-v0.1 |
| 근거 | 비즈니스 정책서 v0.3 (BP-AUTH-003, BP-CONTENT-001, BP-CHAL, BP-ENR, BP-SUB, BP-FEED, BP-POINT, BP-DONE) |
| 작성일 | 2026-11-26 |
| 상태 | 초안 |

## 1. 역할

| 역할 | 설명 | 근거 |
|------|------|------|
| 비회원 | 로그인하지 않은 방문자 | BP-CONTENT-001 |
| 학생 | 가입하면 받는 기본 역할. 아직 해당 챌린지에 신청하지 않음 | BP-AUTH-003 |
| 참여자 | 해당 챌린지 신청 상태가 활성·완주·미완주인 학생 | BP-CONTENT-001-4 |
| 강사 | 관리자 승인을 받은 사용자. 학생 권한을 유지하고, **자기 챌린지**에 대해서만 운영 권한을 가짐 | BP-AUTH-003, BP-AUTH-004 |
| 관리자 | 플랫폼 운영자. DB에서 직접 지정 | BP-AUTH-003 |

## 2. 표기

- **C** 생성 · **R** 조회 · **U** 수정 · **D** 삭제 · **–** 권한 없음
- `본인` 내가 만든 것만, `자기` 내가 강사인 챌린지만, `전체` 모든 데이터
- 괄호는 조건입니다. 권한은 화면이 아니라 DB의 행 단위 보안(RLS)으로 강제합니다 (BP-CONTENT-001-3).

## 4. 현재 구현 상태 (web/, 2026-11-26)

| 영역 | 구현된 CRUD | 미구현 |
