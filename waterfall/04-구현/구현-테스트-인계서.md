## 2. 빌드와 테스트 환경

| 항목 | 기록 |
| --- | --- |
| 재현 가능한 빌드·실행 | Node 20+, `npm install --prefix web` → `npm run build --prefix web` → `npm --prefix web run start -- -p 3123` |
| QA 환경·접근 | 로컬 `http://localhost:3123` (배포 환경 없음) |
| 환경 설정·기능 플래그 | 없음. `web/.env.example`은 Supabase 연결용 키 이름만 있음(미사용) |
| 데이터·마이그레이션 | 메모리 저장소. 서버를 재시작하면 시드 상태로 초기화. 체험 계정은 로그인 화면에 안내(student/instructor @demo.test) |
| 외부 연동 | 없음 (결제·이메일·Supabase 미연결) |

### 3.1 테스트에서 찾은 결함과 조치

| ID | 결함 | 심각도 | 조치 |
| --- | --- | --- | --- |
| BUG-01 | 헤더가 로그인과 상관없이 고정 사용자 "김지은 Lv3"을 표시 | High | 실제 세션 사용자·레벨 표시, 로그인/로그아웃 버튼 |
| BUG-02 | 비로그인 홈에 다른 사람의 오늘의 미션이 보임 | High | 로그인 사용자 것만 표시, 비로그인 시 소개 화면 |
| BUG-03 | 로그인·가입이 "준비 중" 안내만 나옴 | High | 서버 액션으로 실제 처리, 원래 화면으로 복귀 |
| BUG-04 | 인증 결과 점수·스트릭이 화면에서 지어낸 값 | High | 서버 검증 결과 사용 |
| BUG-05 | 인증 직후 화면이 새로고침되며 받은 점수가 사라짐 | Medium | Day 화면 완료 상태에 받은 점수·연속 일수·제출 내용 표시 |
| BUG-06 | 지난 인증 기록이 점수에 반영되지 않아 Lv1로 표시 | Medium | 데모 학생의 지난 Day 인증을 실제 인증·점수로 시드 |
| BUG-07 | 글쓰기 창을 열면 포커스가 게시판 선택에 가서 입력이 사라짐 | Medium | 열릴 때 제목 칸으로 포커스 이동 |
| BUG-08 | 글 수정·삭제 기능 없음, 작성 UI가 일반적이지 않음 | Medium | 모달 작성 창(게시판·제목·본문), ⋯ 메뉴 수정/삭제, 수정됨 표시, 닫기 전 확인 |
